# MultiServerManager

MultiServerManager is a Minecraft plugin designed for Minecraft 1.21+ that integrates with Modern Networking to facilitate the management of multiple servers within a single network. This plugin provides commands to create, delete, and list servers, as well as create spawn points and hub servers. It is ideal for server administrators looking to expand their network with ease.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` directory of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. **Create a Server**: Use the command `/createserver <name>` to create a new server.
2. **Delete a Server**: Use the command `/deleteserver <name>` to delete an existing server.
3. **List Servers**: Use the command `/listservers` to list all servers in the network.
4. **Create a Spawn NPC**: Use the command `/createspawn` to create a spawn point NPC at your current location.
5. **Create a Hub Server**: Use the command `/createhub` to create a hub server.
